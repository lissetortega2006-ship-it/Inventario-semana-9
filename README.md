# Sistema de Gestión de Inventarios

## Descripción
Este proyecto implementa un sistema de gestión de inventarios en consola utilizando Programación Orientada a Objetos en Python.

Permite:
# Añadir productos
# Eliminar productos
# Actualizar cantidad o precio
# Buscar productos por nombre
# Listar inventario

## Estructura del proyecto
modelos/
    producto.py → Clase Producto

servicios/
    inventario.py → Lógica de gestión

main.py → Programa principal con menú interactivo
